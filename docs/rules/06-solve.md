# Ending the mystery

The end triggers: you choose to resolve it at the end of a scene; the clue deck
runs out; a consequence roll reaches 9+.

Then: name the three cards set aside at the start, reveal them, and answer one
question per correct guess, in order —

1. Why was the location significant?
2. Why was the object significant?
3. Why did this treachery befall the object?

Whatever is written is true. A guess naming a card that appears twice across the
truth deck and the set-aside cards is a red herring, and counts as wrong.

*Engine:* `deck.scoreGuesses`, `solve.reveal`, `solve.closeCase`.
